Розклади

    ★ — розклад за замовчуванням у застосунку. Може бути лише один.

    Як опублікувати зміни

    1. Нічого качати не треба — правки вже у файлах docs/schedules/, редактор пише їх сам.
    2. Перевір, що вийшло: git status / git diff docs/schedules
    3. git add docs/schedules && git commit && git push — GitHub Pages опублікує сама, у встановлених застосунках розклад оновиться протягом кількох хвилин.
    4. Розклад із помилками валідації на диск не пишеться — дивись блок «Перевірка» в редакторі.
    1. Натисни Завантажити <id>.json для кожного зміненого розкладу і Завантажити index.json.
    2. Поклади завантажені файли в docs/schedules/ (перезаписуючи старі).
    3. Видалені розклади прибери руками: git rm docs/schedules/<id>.json
    4. git add docs/schedules && git commit && git push — GitHub Pages підхопить самі, у встановлених застосунках розклад оновиться протягом кількох хвилин.
    5. Щоб редактор писав файли сам, запусти його через tools/admin/serve.sh (macOS/Linux) або tools\admin\serve.ps1 (Windows).
