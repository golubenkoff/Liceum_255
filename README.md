# Розклад 7Б

Односторінковий сайт з розкладом занять 7-Б класу Ліцею №255. Показує поточний урок або перерву в реальному часі: назву уроку, зворотний відлік до кінця, і що буде далі.

Сайт доступний на GitHub Pages: **https://golubenkoff.github.io/Liceum_255/**

## Як це працює

- `docs/index.html` — вся сторінка (розмітка, стилі та логіка) в одному файлі.
- Розклад зберігається прямо в HTML-таблиці (`id="schedule"`): у кожного рядка уроку є атрибути `data-start` і `data-end` (час початку/кінця у форматі `ЧЧ:ММ`).
- JavaScript щосекунди перевіряє поточний час і день тижня та підсвічує:
  - **триває урок** — з таймером до дзвінка;
  - **перерва / до початку занять** — з таймером до наступного уроку;
  - **уроки завершено** або **вихідний**, якщо занять на сьогодні (або сьогодні взагалі) немає.
- Час визначається за годинником пристрою користувача, часовий пояс окремо не враховується.

## Структура проєкту

```
.
├── docs/
│   └── index.html   # сторінка сайту (публікується GitHub Pages)
├── LICENSE
└── README.md
```

Папка `docs/` — стандартне місце для GitHub Pages: у налаштуваннях репозиторію (Settings → Pages) обрано джерело `Deploy from a branch`, гілка `main`, папка `/docs`.

## Як змінити розклад

Відкрийте `docs/index.html`, знайдіть таблицю з `id="schedule"` і відредагуйте потрібні клітинки та атрибути `data-start` / `data-end` рядків. Оновлення зʼявляться на сайті автоматично після пушу в `main` (GitHub Pages пересбирає сторінку за деякий час, зазвичай до пари хвилин).
