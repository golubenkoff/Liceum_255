# Розклад уроків

Односторінковий сайт шкільного розкладу, який показує **що відбувається просто зараз**:
який іде урок, скільки лишилось до дзвінка, що буде далі. Відкривається з телефона,
ставиться на головний екран як застосунок і працює без інтернету.

Живий приклад: **https://golubenkoff.github.io/Liceum_255/**

Сайт не прив'язаний до одного класу — розклади лежать окремими JSON-файлами, тож той
самий сайт обслуговує скільки завгодно класів чи вчителів. Клас, показаний за
замовчуванням, задається в каталозі розкладів.

## Що вміє

**Таймер уроків.** Щосекунди перераховує стан і показує один із:

| Стан | Що на картці |
|---|---|
| Іде урок | назва уроку, кабінет, відлік до дзвінка, що буде після перерви |
| Перерва | скільки до наступного уроку і який він |
| До початку занять | відлік до першого уроку |
| Уроки завершено | коли наступний навчальний день |
| Вихідний | визначається за наявністю дня в розкладі, а не «завжди сб-нд» |
| Канікули / свято | за списком дат у розкладі |

Замість цифрового таймера можна увімкнути прогрес-бар. Є короткий звук + вібрація на
межі урок↔перерва.

**Кілька розкладів.** Вибір у налаштуваннях, запам'ятовується. Можна дати людині
пряме посилання на потрібний клас: `?schedule=class7B` — параметр перекриває
збережений вибір.

**Хвилина мовчання.** Щодня о 9:00 рівно одну хвилину картка перемикається на
«Хвилина мовчання» з відліком 60 → 0. Показується завжди, включно з вихідними та
канікулами; у таблицю уроків не додається. Звук на цьому переході не лунає.
Вимикається в налаштуваннях.

**Повітряні тривоги.** Необов'язкова інтеграція (за замовчуванням вимкнена). Коли в
обраному регіоні оголошено тривогу, картка таймера стає повністю червоною з переливом,
зверху з'являється клікабельний напис «Повітряна тривога», а назва уроку лишається
видимою нижче. Клік відкриває карту тривог. Регіон (27 варіантів, за замовчуванням
м. Київ) та інтервал перевірки (10–300 с, за замовчуванням 30) обираються в
налаштуваннях.

Дані: [Карта повітряних тривог — NEPTUN](https://neptun.in.ua/). Це інформаційний
агрегатор, **а не офіційна система оповіщення** — сторінка прямо про це попереджає й
відсилає до офіційних сигналів. Якщо сервісу немає або немає інтернету, з'являється
тиха примітка внизу, а розклад працює як завжди.

**Нотатки й домашка.** Клік по предмету — і до нього прив'язується текст. Комірка з
нотаткою позначається крапкою. Зберігається в браузері, нікуди не надсилається.

**Два види таблиці.** Весь тиждень або тільки сьогоднішній день списком.
Кабінети показуються поруч із предметом.

**Кольори предметів.** Автоматична палітра (кожен предмет отримує свій відтінок),
за бажанням — вручну заданий колір. Вмикається в налаштуваннях, за замовчуванням вимкнено.

**Теми.** Авто / світла / темна.

**PWA.** Ставиться на головний екран Android та iOS, працює офлайн, оновлюється сама:
щойно розклад змінили в репозиторії, встановлені застосунки підхоплять це самі, без
перевстановлення.

## Що всередині

```
docs/                     ← публікується GitHub Pages
  index.html              ← уся сторінка: розмітка + стилі + логіка в одному файлі
  schedules/
    index.json            ← каталог: які розклади існують і який показувати за замовчуванням
    class7B.json          ← один розклад: дзвінки, дні, канікули, кабінети, кольори
  manifest.json, sw.js    ← PWA: маніфест і офлайн-кеш
  icon-*.png              ← іконки застосунку
  MAINTENANCE.md          ← покрокові інструкції з обслуговування
tools/admin/              ← редактор розкладів (локальний, не публікується)
generate-icons.sh         ← перегенерація іконок
```

Жодного білд-кроку немає — це чисті HTML/CSS/JS. Сторінка відкривається як звичайний
статичний файл, збірка й фреймворки не потрібні.

**Дані відокремлені від коду:** розклади лежать у `docs/schedules/*.json`, а не в
розмітці. Щоб додати клас, треба новий JSON і рядок у каталозі — правити `index.html`
не потрібно.

## Формат розкладу

```json
{
  "id": "class7B",
  "name": "7-Б клас",
  "subtitle": "Ліцей № 255 · Класний керівник: …",
  "isDefault": true,
  "updated": "2026-09-02",
  "bells":   [{ "start": "08:30", "end": "09:15" }],
  "days":    [{ "dow": 1, "short": "Пон.", "full": "Понеділок", "lessons": ["Фізика"] }],
  "holidays":[{ "start": "2026-10-26", "end": "2026-11-01", "name": "Осінні канікули" }],
  "subjectRooms":  { "Фізика": "214" },
  "subjectColors": { "Робототехніка": "#0891b2" }
}
```

`lessons[i]` відповідає `bells[i]`, порожній урок — `""`. `dow` — 1..7 (пн..нд),
кількість днів довільна. `holidays`, `subjectRooms` і `subjectColors` необов'язкові.

## Редактор розкладів

Щоб не правити JSON руками, у репозиторії є локальний редактор із таблицею дзвінків,
днів, канікул, кабінетів і кольорів:

```bash
./tools/admin/serve.sh 8000
# сторінка:  http://localhost:8000/docs/
# редактор:  http://localhost:8000/tools/admin/
```

На Windows — `powershell -ExecutionPolicy Bypass -File tools\admin\serve.ps1`
(працює і без встановленого Python).

Запущений так, редактор пише зміни **прямо у файли** `docs/schedules/` — лишається
тільки закомітити. Розклад із помилками валідації на диск не потрапляє. Якщо відкрити
редактор через звичайний статичний сервер, він перемкнеться в режим завантаження:
правки живуть у браузері, а файли викачуються кнопками.

Редактор не публікується на GitHub Pages — він лежить поза `docs/`.

## Запуск і публікація

Подивитись локально:

```bash
python3 -m http.server 8000   # далі http://localhost:8000/docs/
```

Опублікувати: `git push` у `main`. GitHub Pages (Settings → Pages → `main`, папка
`/docs`) пересбирає сайт сам, зазвичай за пару хвилин.
