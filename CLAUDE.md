# CLAUDE.md

Контекст для Claude Code при работе с этим репозиторием.

## Что это

Одностраничный сайт расписания 7-Б класса (Ліцей № 255, класний керівник Лапач М.П.).
Опубликован через GitHub Pages из папки `docs/` ветки `main`:
**https://golubenkoff.github.io/Liceum_255/**

Никакого билд-шага нет — чистый HTML/CSS/JS, весь функционал в одном файле `docs/index.html`
(inline `<style>` + inline `<script>`). Это осознанно: страницу редактирует один человек
руками, фреймворк/сборка была бы лишней.

## Структура репозитория

```
docs/                     ← публикуется GitHub Pages (Settings → Pages → main /docs)
  index.html              ← вся страница: разметка + CSS + JS в одном файле
  manifest.json           ← PWA-манифест (иконка, имя, цвета)
  sw.js                   ← service worker: офлайн-кеш + автообновление
  icon-192.png            ← иконка PWA 192×192
  icon-512.png            ← иконка PWA 512×512
  apple-touch-icon.png    ← иконка 180×180 для iOS "На экран Домой"
  MAINTENANCE.md          ← пошаговые инструкции: как поменять расписание/каникулы/иконку
generate-icons.sh         ← скрипт в корне репо: перегенерирует иконки + бампит кеш sw.js
```

## Как это устроено (внутри index.html)

- **Таблица расписания** — обычный `<table id="schedule">`, каждая строка урока имеет
  `data-start="HH:MM" data-end="HH:MM"`. JS каждую секунду (`setInterval(update, 1000)`)
  сравнивает текущее время с этими атрибутами и подсвечивает текущий/следующий урок.
- **Статус-карточка** сверху — "Зараз йде урок: …" / "Перерва. Наступний урок: …" /
  "Сьогодні вихідний" / "Канікули".
- **Каникулы/праздники** — массив `HOLIDAYS` в начале `<script>`. Если сегодняшняя дата
  попадает в диапазон — показывается "Канікули/свято" вместо расписания. Сейчас заполнен
  предварительными датами на 2026/2027 учебный год (осенние/зимние/весенние/летние),
  требуют уточнения по приказу лицея (см. `docs/MAINTENANCE.md`).
- **Настройки** (шестерёнка ⚙ вверху страницы, хранятся в `localStorage.rozkladSettings`):
  - `theme` — авто/светлая/тёмная. По умолчанию `auto`.
  - `subjectColors` — цветные полоски/подложка по предмету. **По умолчанию выключено.**
  - `progressBar` — прогресс-бар урока/перемены вместо цифрового таймера. По умолчанию выключено.
  - `sound` — короткий бип + вибро при смене урок↔перемена. **По умолчанию включено.**
    Учти: браузеры блокируют звук без жеста пользователя (autoplay policy) — первый бип
    после открытия страницы может быть беззвучным, пока юзер не кликнет хоть куда-то.
- **Вид "тільки сьогодні"** — кнопка над таблицей переключает полную неделю / только
  сегодняшний день списком. По умолчанию `today` (задаётся один раз, дальше запоминается
  в `localStorage.viewMode`).
- **Нотатки/домашка** — клик по предмету в таблице открывает `prompt()`, текст лежит в
  `localStorage` по ключу `note_d{день}_r{номер_урока}`. Точка-индикатор на ячейке = есть заметка.
- **PWA / установка на телефон**:
  - `manifest.json` + `sw.js` + иконки — стандартный набор для "Добавить на экран Домой".
  - Блок "📲 Встановити як застосунок" внизу страницы: кнопка (если браузер поддерживает
    `beforeinstallprompt`, т.е. Android/desktop Chrome) + разворачиваемые инструкции для
    Android и отдельно для iOS Safari (там нативного диалога нет — только текстовая инструкция).
  - Если сайт уже открыт как установленное приложение (`display-mode: standalone`) —
    блок сам скрывается и показывает "✅ Застосунок уже встановлено".
- **Автообновление PWA** — `sw.js` тянет `index.html` network-first с `cache:'no-store'`
  (т.е. при наличии интернета всегда свежий контент, без правок версии кеша). Страница
  раз в 5 минут и при возврате на вкладку дёргает `registration.update()`; когда новый
  service worker становится активным — страница сама делает `location.reload()`.
  Так что при обычной правке расписания в `index.html` ничего вручную бампать не нужно —
  просто закоммить и запушь.
- Версию `CACHE_NAME` в `sw.js` вручную поднимать нужно, только когда меняются файлы,
  которые SW кеширует статично при `install` (иконки, `manifest.json`) — это делает
  `generate-icons.sh` автоматически.

## Как работать с проектом

**Локальный просмотр:**
```bash
cd docs
python3 -m http.server 8000
# открыть http://localhost:8000/index.html
```
Service worker и install-prompt нормально работают на `localhost` (Chrome считает его
доверенным origin), так что PWA-функциональность можно тестировать локально.

**Деплой:** просто `git push` в `main` — GitHub Pages сама пересоберёт `docs/`.
Изменения в `index.html` подхватываются у уже установленных пользователей автоматически
(см. автообновление выше), обычно в течение нескольких минут/при следующем открытии.

**Обновить расписание / каникулы / иконку** — подробные пошаговые инструкции в
[`docs/MAINTENANCE.md`](docs/MAINTENANCE.md). Начинай оттуда, не с этого файла.

**Иконки:** никогда не редактируй `icon-*.png` вручную — перегенерируй скриптом:
```bash
./generate-icons.sh              # тот же класс "7Б", те же цвета
./generate-icons.sh "8А"         # сменился класс — новый текст на иконке
```
Скрипт сам кладёт PNG в `docs/` и бампит `CACHE_NAME` в `sw.js`.

## Проверка после правок

Файл большой и монолитный (HTML+CSS+JS вместе), поэтому после любой правки стоит
как минимум:
```bash
node -e "
const fs=require('fs');
const html=fs.readFileSync('docs/index.html','utf8');
new Function(html.match(/<script>([\s\S]*)<\/script>/)[1]);
console.log('JS syntax OK');
"
```
— это ловит синтаксические опечатки в `<script>` до пуша. Визуально проверять
через локальный сервер + headless Chrome screenshot (`--headless --disable-gpu
--screenshot=out.png`), если под рукой нет обычного браузера.

## Договорённости по стилю

- Весь текст на странице (для учеников/родителей) — **украинский**.
  Служебные доки (этот файл, `MAINTENANCE.md`) и комментарии в коде — можно на русском,
  так исторически сложилось в этом репо.
- Не тащить сюда фреймворки/бандлеры без явного запроса — страница должна открываться
  как один статический файл.
- Цветовая база: зелёный (#16a34a/#22c55e) = "сейчас идёт", жёлтый (#f59e0b/#d97706) =
  "дальше/перемена". Новые статусы старайся вписывать в эту же логику, а не изобретать
  третий несвязанный цвет.
